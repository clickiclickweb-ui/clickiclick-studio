## 1. Identidad del proyecto

**Nombre:** CLICKICLICK.studio  
**Autor:** Diego Puelles  
**Ubicación actual:** Barcelona, Catalunya  
**Proyección:** Expansión a Estados Unidos (4-6 meses)  
**Dominio actual:** clickiclick-studio.vercel.app  
**Dominio futuro:** clickiclick.studio (a registrar cuando haya presupuesto)

## 2. Posicionamiento

CLICKICLICK **no construye webs**. Firma obras digitales hechas a medida.

Es un estudio de una persona (Diego) que trabaja como marca (CLICKICLICK). Hybrid Founder: persona y estudio son la misma cosa, presentados con dos caras según convenga.

**NO ES:** agencia, freelance genérico, studio colectivo, empresa escalable.  
**SÍ ES:** estudio artesanal de autor, firma digital premium, obra sobre encargo.

## 3. Propósito de esta web

Este proyecto tiene **triple propósito**, en este orden:

1. **Demostración técnica personal** — Diego se prueba a sí mismo que puede hacer webs a nivel estudio internacional top-tier (Basement, Shader, Lusion, Rabenrifaie).
2. **Posicionamiento estratégico** — Pieza central de la identidad profesional futura. Sirve para la transición a EE.UU. como carta de presentación visual.
3. **Captación premium selectiva** — No es la herramienta comercial principal (ese rol lo cumple el portfolio existente). Aquí solo caen clientes que vienen por referencia, búsqueda específica, o curiosidad hacia el nivel técnico.

**NO es:** herramienta de conversión masiva para pymes locales. Las peluquerías de Martorell no son público objetivo de esta web.

## 4. Audiencia real

**Primaria (ahora, Abril-Septiembre 2026):**
- Pymes ambiciosas española/latinoamericanas que ya pagan €3K+ por web
- Clientes tipo Ana Rafaele (Primaria Stk)
- Referencias personales que buscan calidad, no precio
- Agencias o creativos que podrían subcontratar

**Secundaria (desde Septiembre 2026):**
- Mercado estadounidense: startups, marcas boutique, clientes remotos en dólares
- Reclutadores de estudios creativos (si Diego explora opción empleado además de freelance)

**Dejada fuera conscientemente:**
- Peluquerías, restaurantes y pymes de <€1.500 que atiende el portfolio existente

## 6. Sistema cromático (OFICIAL — NO MODIFICAR SIN RAZÓN FUERTE)

```css
/* BASE — 85% de la web */
--ink: #0A0706;              /* fondo principal */
--cream: #EDE4CE;            /* tipografía principal */
--cream-soft: #B8AB90;       /* texto secundario, metadatos */

/* SIGNATURE — 25% */
--garnet: #A31E38;           /* italic, acentos, firma */
--garnet-deep: #6E1425;      /* hovers, estados activos */

/* CONTRAPUNTO — 15% */
--teal-night: #0B2E3E;       /* secciones frías, fondos alternativos */
--teal-luminous: #7CAFAE;    /* acentos puntuales ("rayos") */

/* ORO — ≤2%, solo 3 usos semánticos */
--gold-aged: #8A7046;        /* año MMXXVI, firma personal, números ornamentales */

/* SECRETOS — ≤1%, easter eggs */
--moss: #2D3A2A;             /* una sección específica */
--lavender-dust: #9B8CB5;    /* un hover único */
```

**Reglas absolutas:**
1. El oro **NUNCA** aparece en botones, CTAs, bordes, backgrounds o iconos generales
2. Los "secretos" (musgo, lavanda) aparecen **UNA sola vez** cada uno en toda la web
3. No hay gradientes de más de 2 colores simultáneos
4. Nunca granate + teal brillante en la misma pantalla (solo teal noche convive con granate)
5. Los colores crean **ritmo emocional** por secciones, no caos visual simultáneo

## 13. Stack técnico (CERRADO)

```
Base:
- Vite + React 18
- Tailwind CSS
- Fontshare (fuentes)

Animation & Interaction:
- GSAP + ScrollTrigger
- Lenis (smooth scroll)
- Framer Motion (micro interactions)
- split-type (text animations)

3D (cuando aplique, no en hero):
- React Three Fiber + drei + postprocessing
- Solo si la sección específica lo justifica

Deploy:
- GitHub (clickiclickweb-ui/clickiclick-studio)
- Vercel (auto-deploy on push to main)
```

**NO se usa:** Next.js (Vite basta), shadcn/ui (componentes custom), localStorage, librerías que no están en esta lista.

## 14. Anti-patterns (lo que NUNCA hacemos)

- Gradientes de 3+ colores
- Fuentes genéricas (Inter, Roboto, Arial)
- Centered hero con centered CTA (cliché)
- Emojis en copy profesional
- Cursor `mix-blend-mode: difference` sobre imágenes
- Bouncy easings
- Lorem ipsum en código final
- Más de 2 colores de marca activos en una sección
- Copy en primera persona plural fake ("we make...")
- Botones con sombra difusa + gradient + border-radius 16px+
